Recursos originales generados con la herramienta integrada ImageGen para esta iteración del proyecto. No contienen texto ni estados de selección: las imágenes acompañan el recorrido y las leyendas explican su estado real.

- `un-pedido.jpg`: búsqueda de una coincidencia. 768 × 512 px; 41.7 KB.
- `elegir-pedido.jpg`: elección entre coincidencias. 768 × 512 px; 51.1 KB.

Se guardaron como JPEG optimizados para la web; los originales generados se conservaron fuera del repositorio. Las imágenes son decorativas (`alt=""`) porque la información relevante se presenta como texto accesible junto a ellas.

La web ahora utiliza variantes verdes coherentes con el encabezado y la portada: `../pedido-hero-verde.jpg` para la búsqueda directa y `elegir-pedido-verde.jpg` para la elección. Los dos JPEG anteriores se conservan como fuentes. Ver [variantes activas y prompts de edición](../VARIANTES-IDENTIDAD.md).
